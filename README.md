# Employee Scheduling and Labor Cost Analytics Database

## Project Overview
This BUS 385 Business Data Management project uses MySQL to analyze employee scheduling, staffing coverage, and labor costs.

## Database Tables
The database contains six tables:
- **Department:** Stores department information.
- **Employee:** Stores employee information.
- **Availability:** Stores employee availability.
- **Shift:** Stores scheduled shifts and staffing requirements.
- **ShiftAssignment:** Connects employees to their assigned shifts.
- **TimeRecord:** Stores clock-in, clock-out, and break information.

## SQL Analysis
SQL queries were developed and tested to:
- Calculate scheduled hours by department.
- Estimate labor costs by department and shift.
- Identify shifts with insufficient staffing.
- Analyze employee work hours.
- Compare scheduled and recorded hours.
- Identify missing or invalid time records.
